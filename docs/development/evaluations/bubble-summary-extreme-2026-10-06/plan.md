# 強圧縮候補の比較計画

未検証の候補。本番プロンプトへ未採用。現行の共通・単独・連続規則は同じ。圧縮規則のみ、同じ内容の再説明を避ける、明示文体指定と文体見本を重複させない、主語・同じ対象の述語をまとめる、長い反復は10〜20%を目指す、という指示へ変更した。数値・帰属・否定・範囲・確度・人物の声は削らない。

基準: main b52f3ad の現行プロンプト・送信用wrapper。比較モデル: OpenRouter anthropic/claude-opus-4.6、temperature1、top_p1、max_tokens2048、reasoning_effort none、force_reasoning true。既存の$10検証台帳を継続し、上限を増やさない。

既存ケースT01（数値と未取得）、T05（200字制約）、T06（nullとJSON）、T10（人物の声）、T13/T14（長い反復）を各2回。原文、現行圧縮、候補圧縮からの後続応答を同条件で比較。新規の短い密な指示と、長い説明に短い禁止が埋もれるケースを未使用確認に追加する。

採用条件: 送信wrapper込みで節約が改善し、内容・帰属・文体・ニュアンスの重大な劣化が再現しないこと。文言一致・トークン減少だけで採用しない。入力・出力・使用量・反復・判定理由を保存する。接続復帰後に実行する。
