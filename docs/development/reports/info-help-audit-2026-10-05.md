## 常時表示を残す内容

| 場所 | 理由 |
| --- | --- |
| 要約生成設定・生成済み要約の設定 | 実際に選択されている値・生成履歴 |
| 要約対象数・生成エラー | 操作対象と進行・エラーの状態 |
| ローカルモデル検査結果・未検査・実行中・モデルカード | 実測結果、現在の状態、選択候補の内容 |
| Google同期 | 同期方式、接続前のデータ利用・暗号化説明、競合の選択、切断確認、暗号化形式の移行 |
| インポート | ファイル選択の案内、置換時のデータ削除確認 |
| 同期変更レビュー | 未確認の変更がある状態 |
| 初回案内の本文・ヘルプ・About | 説明そのものが画面の目的 |
| 起動待機・ErrorBoundary・検証ページ | 待機・障害からの復旧案内、検証画面の本文 |
| プリセット・モデル検索結果 | 選択する内容の比較に必要な説明 |

## リセット

対象選択画面は範囲・形式の個別リセットと、範囲・形式・専用設定の一括リセットを備える。要約専用設定の個別リセットと一括リセットは「専用設定なし＝チャット設定を使用」に戻す。専用モデル設定の画面では、既存パラメータ別リセットに加えてモデル・強制思考の個別リセットと設定全体のリセットを設ける。一括リセットは標準のモデル・生成設定に戻し、モデル別の保存値も消す。APIキー、会話、localStorage全体は操作しない。
